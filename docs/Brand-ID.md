**Domain:** `alfredterminal.xyz`

---

# 1. Brand Name

## Primary Brand Name

**Alfred Terminal**

Always capitalize both words.

Correct:

> Alfred Terminal

Avoid:

> alfred terminal  
> ALFRED TERMINAL  
> AlfredTerminal  
> Alfred Resume Builder

The product name is **Alfred Terminal**, not "Alfred AI" and not "Alfred Resume Builder."

---

# 2. Brand Concept

Alfred Terminal is an AI-powered workspace for job seekers.

The name combines two ideas:

### Alfred

Represents an intelligent assistant.

The product should feel like a capable personal career assistant that helps the user prepare applications without taking control away from them.

### Terminal

Represents precision, control, technology, and execution.

It gives the brand a technical identity and creates room for future career-oriented tools.

The brand should feel more like a **modern developer tool / productivity terminal** than a traditional recruitment website.

---

# 3. Current Product Scope

Alfred Terminal currently provides exactly two core capabilities:

## 01 — Tailored Resume

Users provide:

- Their existing resume
- A target job description

Alfred Terminal analyzes the target role and creates a tailored, ATS-friendly version of the candidate's resume while preserving factual accuracy.

### Core promise

> **Tailored to the job. True to you.**

---

## 02 — Cover Letter

Users can generate a customized cover letter based on:

- Their resume
- The target job description

### Core promise

> **A cover letter written for the role, not a template.**
